☕ 1. Big Picture: What is this Project?

Think of this software as the central nervous system of a coffee roastery & trading business. It automates and connects all five factory departments so that no coffee, no money, and no bag is ever lost.

🏗️ 2. System Architecture

The application is built as a fast Single Page Application (SPA) using TypeScript, HTML5, CSS3, and Vite. It works completely offline using an in-browser Mock Database, and is 100% prepared to connect to a Spring Boot / PostgreSQL backend.

🔍 4. Every File Explained in Plain Words

🏢 Core Application Engine

File What it does in simple words Real-world coffee analogy
src/main.tsx The Master Key. The very first file executed when opening the website. Boots the portal and starts the clock. Unlocking the factory gates in the morning.
src/app.ts The Floor Supervisor. Listens to every click, keypress, and form submission. Decides which screen to show. The floor manager directing staff where to go.
src/shell.ts The Physical Building. Renders the stationary left sidebar, user profile capsule, breadcrumbs, and auto-logout timer. The reception area, hallways, and signs on the walls.
src/state.ts The Brain's Memory. Remembers who is signed in (Owner, Manager, Roaster), what permissions they have, and active page. A clipboard holding today's active work notes.
src/ui.ts The Toolbox. Reusable pop-up dialogs, tables, input boxes, badges (ACTIVE, HOLD), and toast alerts. Standard measuring cups, pens, and stamps used in every room.

🔌 Data & Network Layer

File What it does in simple words Real-world coffee analogy
src/api.ts The Office Courier. Sends and receives data between screens and database. If offline, safely connects to mock-db.ts. The internal mail clerk carrying order slips between departments.
src/mock-db.ts The Browser Ledger. Stores realistic coffee batches, inventory, customers, and cash right in your browser. A practice company ledger loaded with real business numbers.

💡 Quick Cheat Sheet

  • To edit Retail Counter sales & billing: check src/views/counter.ts
  • To edit Daily Roasting or QC rules: check src/views/ops.ts
  • To edit Staff, PINs or Roles: check src/views/admin.ts
  • To edit Sample Data & Balances: check src/mock-db.ts
  • To edit Colors & Layout rules: check src/styles/preview-theme.css
